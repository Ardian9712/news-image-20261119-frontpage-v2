One dense page sums up a full day through a masthead, three lead panels, a numbered story grid, a map, and a briefs list. The composition uses an editorial hierarchy to bring many events together into a single, cohesive front page.

## Run

Use Node.js 24 or newer:

```sh
npm start
```

The program copies the bundled `entry.png` to `/output/entry.png`, then reads the output back and prints its SHA-256 verification result. Set `OUTPUT_DIR` to choose another output directory.
